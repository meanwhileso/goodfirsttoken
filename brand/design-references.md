# Good First Token design references

Pulled on 2026-09-26 while choosing the brand. Mobbin covers the app
surfaces: the install flow, leaderboard, and feeds. Refero covers the
marketing styles. Each entry says what we took. Nothing is copied.

## Install and "point your agent" flows

- [Base MCP, "Give your agent a wallet"](https://mobbin.com/sites/sections/fbb5edd9-729e-4038-9f2c-8cd473fd3428):
  pick your AI tool (Claude, ChatGPT, Claude Code, Codex, Cursor), connect,
  copy prompt, try it. Source of the harness tabs and the one-prompt install.
- [Railway, agents hero](https://mobbin.com/sites/sections/82b84eaf-1bf6-4670-bfff-585aadd9ae6c):
  "One command. That's it." with CLI and Prompt tabs over a row of agents.
  Source of the harness list. The redesign replaced its tabs with one line of
  open-in links and a setup disclosure.
- [Browserbase hero](https://mobbin.com/sites/sections/c5c98154-679e-45ff-9a81-58feae8c0ca5):
  a "Copy prompt" action beside the primary button.
- [Giga, pip install section](https://mobbin.com/sites/sections/a2004615-5fee-4e7d-9f84-602f3f1ab1f0):
  a single command in a pill with a copy button.

## Leaderboards

- [Devin, merged PRs leaderboard](https://mobbin.com/screens/e7e5407f-d6f8-40b8-9f05-86745faeb75c):
  week, month, quarter, all-time tabs over merged PRs. Confirms ranking by
  merged PRs.
- [Vercel AI Gateway leaderboards](https://mobbin.com/screens/abbadfbe-0db6-453b-b9bc-ccb7ce2d60ed):
  clean numbered two-column list. Source of the plain numbered rows.

## Activity feeds

- [Basecamp, latest activity](https://mobbin.com/screens/b71d21b5-1078-44a4-adb3-9583531a6059):
  day-grouped timeline. Source of the person page's history grouping.
- [Klaviyo, activity feed](https://mobbin.com/screens/f509ead5-2779-4937-b9fd-b0ad4760ba5a):
  dense single-line rows with a time column.

## Marketing styles (Refero)

- SST (sst.dev): light technical-document feel, code card as the hero motif.
- Tailwind CSS (tailwindcss.com): black-and-white, type-led, accent only in
  code. Closest to direction A's restraint.
- Hugging Face (huggingface.co): light, data-console, small colorful badges on
  ranked panels.
- PostHog (posthog.com): proof that a developer brand can be warm without
  going dark.
