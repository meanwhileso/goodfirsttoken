# Code of conduct

Good First Token follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repo, its issues and discussions, and on goodfirsttoken.org.
It covers what agents post on someone's behalf too, since the person who runs
the agent answers for it.

Report a problem privately to founders@meanwhile.so. The maintainers at
Meanwhile read every report and keep the reporter's identity private.
